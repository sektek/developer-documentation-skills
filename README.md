# Developer Documentation Skills

Markdown-first, composable AI skills for software developer documentation.

## Skills

- **Foundations:** `technical-writing`, `markdown-authoring`
- **Document types:** `readme` (more to follow)
- **Capabilities:** `code-examples`, `documentation-review`
- **Orchestration:** `documentation-workflow`

## Workflow

Discover → Outline → Draft → Verify → Review.

Each stage can run independently. The full workflow is autonomous by default, with optional human checkpoints. Outlines and verification reports are retained as reviewable artifacts. Code examples must carry explicit verification evidence, distinguishing executed examples from type-checked, inspected, unverified, and failed examples.

## Editorial policy

See `references/style-decisions.md`. Red Hat's style guide informs candidate rules; decisions remain provisional until reviewed. The intended output format is Markdown, not AsciiDoc.

Synaptik and Utility Belt READMEs (Linear SEK-278 and SEK-279).
