# README

A developer README should answer: What is this? When should I use it? How do I install it? How do I accomplish a minimal useful task? Where can I learn more?

Prefer a concise overview, a working quick-start example, installation and prerequisites, major capabilities, and links to detailed guides/reference material. Explain the mental model where necessary without duplicating the full API reference. Tailor sections to the library rather than forcing a fixed template.
