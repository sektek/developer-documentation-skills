# Technical writing

Write clear, accurate developer-facing documentation. Prefer direct language, active voice, concrete nouns, and consistent terminology. Address the reader as “you” where natural. Avoid filler, unsupported claims, and unnecessary jargon. Distinguish requirements from recommendations. Use the Red Hat style guide as a source of candidate conventions, not as an unquestioned authority. Consult `references/style-decisions.md` for local decisions.
